# SEO 分析 Agent

输入网站 URL，自动完成整套 SEO 诊断，输出结构化分析报告。

## 检测维度

- TDK 检测（Title / Description / Keywords）
- robots.txt / sitemap.xml 校验
- 页面基础 SEO（H1 / 图片alt / Canonical / OG / 结构化数据 / 链接）
- 技术问题（HTTPS / 移动端 / 性能 / 压缩 / lang / favicon）
- 内容缺陷（字数 / 文本比 / 标题 / 段落）
- 整改建议（按优先级排序）
